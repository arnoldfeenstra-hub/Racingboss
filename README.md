# Racingboss

Research notes on [Racing Boss](https://www.racingboss.com/), the free online Formula-racing management game (formerly F1TIME, running since 2002).

- [docs/racingboss-research.md](docs/racingboss-research.md): how the game works: league pyramid, economy and prize tables, car design and suppliers, staff and markets, practice, qualifying and race orders, season reset, the simulation model inferred from public data, and strategy notes.
